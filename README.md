# Anemia Prediction System

## Overview
The Anemia Prediction System is a web-based application developed using Django and Machine Learning to predict whether a person has anemia based on blood test data.

## Features
- Predicts anemia using a trained machine learning model
- User-friendly web interface
- Displays prediction results instantly

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## How to Run
1. Install the required packages:
   pip install -r requirements.txt

2. Run the server:
   python manage.py runserver

3. Open your browser and visit:
   http://127.0.0.1:8000/
